# 方寸食光 0.9.7r1 复验

导入组合包并同时启用 BP 与 RP。运行 `/function mcpe_food/build_info` 应显示 `0.9.7r1`。包管理器使用数值版本 `0.9.8`。

| 内容 | 检查 |
|---|---|
| MacBook Air M5 和 LEGION | 从侧面检查屏幕和底座成 90°，从正面和低角度检查键盘画面。 |
| 便民服务终端和自助政务终端 | 从正面和侧面检查完整画面可见、壳体无遮挡。 |
| 模拟 Linux 桌面 | 空手点电脑，选「文件管理器」→「README.txt」，阅读内容，返回同一路径。 |
| Linux 终端 | 输入 `mkdir Projects`，再输入 `open Documents/notes.txt`。关闭阅读器应返回终端。 |

对上述模型分别使用普通画质和官方灵动视效复验。用备份世界检查之前放置的摆件能否读取同一 ID 的新模型。
