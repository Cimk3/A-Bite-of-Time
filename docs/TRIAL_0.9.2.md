# 0.9.2 候选复验

导入FoodAndTable-0.9.2.mcaddon，启用同批次BP与RP，构建标识0.9.2-candidate.1。先在旧世界副本试用，不正式发布。

`/function mcpe_food/build_info` 核对BP构建标识。`/function mcpe_food/tasting_new` 取得本轮47件；也可使用park、cafe、finance、police_station分类命令。

1. 新放置正面对玩家；公园与所有多格设备、柜架的屏幕、图案、顶盖和部件在四向均连续，无左右错拼或漂浮。
2. 旧0.9.0/0.9.1结构按有界队列在原占地修正，进入世界后稍等恢复；跨区块返回后继续恢复，不能丢柜内物品或重复掉落。已经缺部件的结构按整件回收处理。
3. 咖啡机杯具与出水组、POS支架、封口机进料区、加料盒食品、磨豆机豆仓/出粉口、防暴柜装备能看见且连接正常。
4. 长椅3座和卡座4座，朝向座位前方/对侧；潜行离座后重新使用正常。路灯仍为4格高，只有灯头亮度15。
5. 西点柜6槽、物品柜6槽和架子12槽，展示物贴住层板，正面朝外，无跨层重叠。存取和整件回收数量保持。
6. 全47件分别看正面、背面、侧面；普通模式和官方灵动视效各检查一次，注意玻璃/屏幕/纸杯和食品受光。

[全目录检查](AUDIT_0.9.2.md)收录实际资源预览与检查范围；这些不是实机截图。仍有异常时请保留构建标识、物品、朝向、完整错误文字及画面。
