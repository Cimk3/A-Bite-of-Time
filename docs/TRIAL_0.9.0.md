# 0.9.0 候选试用

本轮按用户要求先交付完整候选，正式发布等待实机反馈。

导入 FoodAndTable-0.9.0.mcaddon，在世界中启用同批次 BP 和 RP。构建标识应为 0.9.0-candidate.1。使用世界副本测试。

- /function mcpe_food/tasting_new 发放本轮47件物品。
- /function mcpe_food/park 发放公园物品。
- /function mcpe_food/cafe 发放咖啡店物品。
- /function mcpe_food/finance 发放金融物品。
- /function mcpe_food/police_station 发放警察局物品。

落地大型物品点击完整地面顶面放置，需要全部占地有支撑、上方空间足够。空手交互收回。长椅与卡座空手交互坐下，潜行离座，潜行交互进入收回菜单。

展示柜手持普通模组物品交互后选择空槽放入一件，空手交互取回。西点柜只接受料理，物品柜和架子支持更多物品。自定义名称、说明或额外数据的物品会被拒绝。收回整件需要背包容纳柜体及内容。

请分别使用普通模式和官方灵动视效检查以下项目。

1. 路灯四格高，只有灯头发出15级方块光。
2. 长椅可同时坐3人，卡座可同时坐4人，离座后可再次使用。
3. 真实方块能够阻挡移动，卡座入口与桌下空间符合模型。
4. 西点柜玻璃透明，两层共6个食品可见。
5. 物品柜6槽、架子12槽，放入与取回数量一致，满载后重进世界仍正确。
6. ASML占6×4、4格高，四个方向放置均不侵占其他格。
7. 金融大屏与走势条尺寸、方向正确，画面为静态示例。
8. NovaCare与AuraMed广告品牌、设备图像、安装方向可辨认。
9. 旧0.8.6摆件、料理和存档内容正常。
10. 联机同时操作、跨区块离开和返回、安卓触屏交互需要单独确认。

出现异常时记录物品名称、放置朝向、BP/RP构建标识、图形模式和内容日志，并提供对应画面。
