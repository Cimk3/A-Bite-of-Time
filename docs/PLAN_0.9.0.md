基线为 v0.8.6、提交 e281a8d。交付全部 47 件内容的 0.9.0-candidate.1，用户试用并处理反馈后再正式发布。新增内容供创造模式使用。两个医疗广告须先绘制草图。

- 咖啡店 13 件：卡座 3×2×1、4 座和桌面；透明西点柜 3×1×2、两层各 3 槽；咖啡机 2×1×2；磨豆机 1×1×2；三瓶糖浆；单马克杯；双马克杯；纸杯；纸袋；收款机 2×1×1；打包机 2×1×1；加料盒 2×1×0.75；茶桶 1×1×2。

- 警察局 11 件：对讲机、双机基座、应急医疗箱、监控值班电脑 2×1×1、便民终端和饮水机各 1×1×2、防暴柜 2×1×2、壁挂警示灯、文件柜 2×1×2、接待大厅标识 3×1、指挥屏 4×2。

## 实现约束

- 统一目录描述尺寸、部件格、碰撞、座位和槽位，分格真实方块一次放置、整件回收，失败回滚；未加载区块等待恢复。
- 原有 DecorRecord v1 与旧索引兼容。长椅和卡座按需生成隐藏乘坐实体，空手坐下，潜行离座和收回。
- 西点柜接受本模组料理和甜点。柜、架支持至少 90% 的本模组公开物品；有三维模型复用模型，其余使用图标薄牌。拒绝具有自定义名称、说明或额外数据的物品；整件收回前核对背包容量。
- 西点柜使用真正透明玻璃；优先完成与食品同屏小样。新增资源保持私有路径和官方灵动视效 PBR，不覆盖原版资源。普通模型 128px 色图、图标及同尺寸 MER，整件基础几何不超过 256 方块体。
- 金融屏每格 64 像素，最大 640×320；医疗广告分别 320×320 和 384×384。广告草图与提示词归档。
- 先完成路灯、一个座位、一个展示槽的小样，随后实现完整内容。定向测试和预览用于迭代，最终串行运行 npm run package 和 python tools/verify_archive.py。
