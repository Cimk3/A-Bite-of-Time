# 方寸食光 0.9.7 候选复验

同时启用 0.9.7 候选包的 BP、RP。输入 `/function mcpe_food/build_info` 核对构建号，输入 `/function mcpe_food/tasting_new` 领取七件新品。通过创造物品栏取得四件模型有更新的旧物品。

| 内容 | 游戏内检查 |
|---|---|
| 两台笔记本 | 分别从正面、侧面、背面及低角度观察。屏幕和边框应随同一块上盖倾斜，画面无条纹、悬空边框或穿模。 |
| 警用和政务终端 | 检查屏幕接缝、两侧过渡件、屏幕文字、底部出件区和背面检修面板。 |
| 医用磁共振设备 | 预留宽 3 × 深 4 × 高 3 格的空间与足够地基。逐向摆放，从前后两端检查开口，并检查床轨、后罩散热与收回。 |
| 四道中餐 | 用白瓷盘装大闸蟹和蚝烙、用酒红长盘装卤水鹅、用碗装福果甜芋泥。检查托盘、柜内与原比例摆盘。 |
| 互动电脑 | 空手点按进入桌面。打开终端，运行 `mkdir Projects`、`ls`、`cd Projects`、`pwd`、`cat ../README.txt`。运行 `exit` 并查看文件浏览器。两位玩家同时操作，验证各自目录隔离。潜行空手回收。 |
| 健身房广告屏 | 预留宽 4 × 高 2 格墙面，检查方向、海报文字、深蹲剪影、屏框和背面挂架。 |

普通模式与官方灵动视效分别检查。旧存档先备份，再用已放置笔记本、终端、台面摆件和墙屏的 0.9.6 世界检查升级。真实客户端结果待记录。
