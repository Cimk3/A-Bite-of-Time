# 0.9.6 逐件复验

导入 FoodAndTable-0.9.6.mcaddon，在测试世界和已有西点柜的旧世界副本中启用同一批 BP 和 RP。运行 `/function mcpe_food/build_info`，确认 `0.9.6-candidate.1`。

| 物品 | 实机对照 |
|---|---|
| MacBook Air M5 | 薄壳、宽触控板、紫色屏朝键盘、转轴和边侧接口 |
| LEGION 游戏本 | 黑壳与分区键盘、蓝色屏朝键盘、背部进出气与接口 |
| 双屏显示器套装 | 双屏并排，支架、背线、键鼠并列 |
| 三联屏工作台 | 两边向内收，中间宽屏，三支点衔接 |
| 检票闸机 | 两基座、读卡面、透明闸翼与转轴相接 |
| 自助售票机 | 路线图、出票凹槽和后检修盖 |
| 西点柜 | 两层各三件，底部贴层板，四向看玻璃没有遮掉糕点 |
| 意式咖啡机 | 两冲煮头、托盘杯具、蒸汽棒、压力表和后散热 |
| 磨豆机 | 豆仓能见豆粒，出粉口、接粉杯、后通风 |
| 三瓶糖浆组合 | 三瓶标签不同，泵头与瓶身连贯，盒底完整 |
| 警察局便民服务终端 | 深蓝前脸、警务静态界面与后盖 |
| 饮水机 | 蓝色水桶有承托，冷热键、喷嘴、凹腔和托盘 |
| 防暴装备柜 | 三种装备各有固定点，柜后板和通风可见 |
| 自助政务服务终端 | 青灰机壳、政务静态界面、扫描区和凭条区 |

普通模式和官方灵动视效各查看一次。四向摆放后看正面、背面和两侧，走远再返回确认外观正常。西点柜用小点心、带盘食物及大件食品存满六槽，验证重进世界、取回某槽及整柜回收。旧设备位置、碰撞和槽内食品应保留。
