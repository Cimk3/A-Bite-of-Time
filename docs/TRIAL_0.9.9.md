# 0.9.9 社区邮局复验

导入同一批行为包与资源包。运行 `/function mcpe_food/build_info` 核对 `0.9.9-release.1`，再运行 `/function mcpe_food/post_office` 领取九件物品。

| 物品 | 检查 |
|---|---|
| 邮政柜台 | 按四个方向放置，检查三格占地、背面抽屉和柜员侧空间。 |
| 分拣格柜 | 数清四列三行分拣格，检查背面柜门、放置和回收。 |
| 包裹自提柜 | 检查双色柜门、编号、操作屏、背面散热口及三格占地。 |
| 方形、圆柱邮筒 | 并排摆放，从正面检查前投递口，从背面检查取件门。 |
| 称重台、三种纸箱 | 摆到桌面，从侧面检查大小区别、秤盘、胶带和运单。 |

分别用普通画质和官方灵动视效检查。其中包裹自提柜与称重台采用固定示例画面，屏幕为指定发光区域。实机结果待记录。
