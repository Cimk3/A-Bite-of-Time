# 方寸街区 / Fangcun District 1.0.0

《方寸食光》现更名为《方寸街区》。本版新增 19 件创造模式摆件，包括酒店推车和壁挂吹风机、图书陈列家具、便利店设备、外卖打包袋、带伞雨伞架和四分类垃圾桶。台灯提供常亮光源，冷柜和保温柜使用透明展示。

本版也精修微波炉等 10 件既有摆件，并为放置失败提供支撑、空间、占用和未加载提示。

导入 FangcunDistrict-1.0.0.mcaddon 后，启用同一批行为包和资源包。在创造模式运行 /function mcpe_food/tasting_new 可领取本版新品。升级前先复制旧世界。

基于已发行的 0.9.9 包核对旧物品与方块定义、包 UUID 和展示索引。目标为 Minecraft 基岩版国际正式版 26.52。Windows、安卓、官方灵动视效、联机和旧世界的真实客户端复验待记录。
