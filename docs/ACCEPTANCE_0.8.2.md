# 0.8.2-rc.1 Windows 验收

请用 `FoodAndTable-0.8.2.mcaddon` 导入匹配的行为包和资源包。发给验收者的 `SHA256SUMS.txt` 对应同一批候选附件。Windows PowerShell 可用 `Get-FileHash .\FoodAndTable-0.8.2.mcaddon -Algorithm SHA256` 核对。

1. 新建创造世界，启用名称含 `0.8.2-rc.1` 的 BP 和 RP。执行 `/function mcpe_food/build_info` 核对构建号，再执行 `/function mcpe_food/tasting_new` 领取 17 件新品。检查医疗、军警与广告三个分组。
2. 复制曾在进入时退出的旧世界，打开副本的世界设置，将 BP 和 RP 升级为本候选批次。进入世界后检查旧摆件与旧大屏是否完整恢复。
3. 放置、回收几件新医疗和警务摆件。把豪都大酒店广告屏挂在完整的 7 格宽、5 格高墙面上，前方留空一格。让一块屏跨过区块边界。检查中文标题、朝向和整件回收。
4. 离开相关区块再返回，退出世界并重新进入。检查旧物品、新摆件与广告屏能正常恢复，内容没有丢失或重复。通过条件为无崩溃、无脚本看门狗退出。

验收结果请注明 Windows 客户端版本、构建号和通过的步骤。若发生退出，请保留「显示详情」、客户端内容日志和触发步骤。正式发布以这批候选包的 Windows 结果为准。
