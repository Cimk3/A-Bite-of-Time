# 0.9.5 候选复验

导入 FoodAndTable-0.9.5.mcaddon。在一个测试世界和旧世界副本中同时启用同批 BP 和 RP。用 `/function mcpe_food/build_info` 核对 `0.9.5-candidate.1`，再执行 `/function mcpe_food/tasting_new`。下表格数为宽×深×高的模型最大外廓。

| 物品 | 格数 | 实机重点 |
|---|---|---|
| 爆米花机 | 1×1×2 | 四侧玻璃能看到吊锅与爆米花，柜门、脚座及后散热孔完整 |
| 双口饮料机 | 1×1×1 | 台面摆放，两个喷嘴和接水盘留有开口，后接头与机身相接 |
| 灯箱海报柜 | 2×0.25×3 | 四向墙面紧贴，完整展示 LUNAR SIGNAL，暗处只有画面微亮 |
| 调音台 | 2×1×0.5 | 两格台面支撑，推子、电平条、旋钮和背面接线口清晰 |
| 监听音箱 | 1×1×1 | 单只可单独摆放，两只可相邻，正面双单元与背面接口完整 |
| 跑步机 | 1×2×1.5 | 两格深，跑带、扶手、屏幕与机脚相接 |
| 深蹲架 | 2×2×3 | 两个支撑立柱、挂钩和杠铃有清晰连接 |
| 可调卧推凳 | 1×2×1 | 靠背保持斜角，座垫、背垫与支架连接 |
| 三层哑铃架 | 2×1×1.5 | 三层都能辨认，哑铃与层板相接 |
| 拉索训练器 | 2×1×3 | 滑轮、配重、拉索和手柄都有连接 |
| 瑜伽垫收纳架 | 1×1×1.5 | 三卷分明，护栏、底座和侧框连接 |
| 拳击沙袋 | 1×1×3 | 吊链上下都能接住，支架与底脚完整 |

普通画面与官方灵动视效分别检查。四向放置后从正面、背面、双侧查看，走近及走远检查闪烁、缺面和回退方块。验证完整墙面、缺支撑、阻挡、拆除、重新进区块和回收。旧世界副本抽查旧广告、柜架、医疗设备与 ASML 的恢复。
