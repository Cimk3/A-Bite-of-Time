# 方寸街区 1.0.0 实机复验

使用 0.9.9 世界副本，记录客户端版本、系统、显示模式及行为包和资源包构建标识。通过 /function mcpe_food/build_info 查询 BP 标识。

1. 更新前摆好旧 ASML、微波炉和打开款笔记本，并在既有展示柜放入物品。更新后确认同一位置和朝向、柜内物品与回收数量。
2. 在创造模式使用 /function mcpe_food/tasting_new 领取 19 件新品，摆放四个方向的落地设备、壁挂吹风机与台面件。台灯需要完整台面，普通模式下需照亮周边。
3. 测试失去地面支撑、上格占用、第一层占用和跨未加载区块。记录实际提示，检查失败后仍能正常放置且原处无残留。
4. 离开摆放区至卸载范围再回来，保存退出并重进。确认大件完整、显示实体不重复、拆除能收回整件。
5. 在普通和官方灵动视效观察玻璃内货物和台灯。另记录安卓导入与触屏、联机并发、密集摆放与重进性能。

如有异常，保留世界副本、摆放方向、坐标和游戏内容日志。当前实机项目待验证。
